# Texas Capitol Watchdog

An independent legislative accountability series by **The Coryell County Scoop**.

## Site

A static, mobile-first, English/Spanish landing page. No database, API keys, backend, paid hosting, or build step required.

- `index.html`: complete site, styles and behavior.
- Language switches only when a visitor clicks EN or ES and persists using localStorage.
- Keyboard-friendly controls, semantic headings, high contrast and responsive layout.
- Direct links to Texas Legislature Online, Legislative Budget Board, Texas Ethics Commission, Comptroller, Legislative Reference Library, and Governor's Office.

## Deployment

Connect this repository to **Cloudflare Pages** (or enable GitHub Pages). For Cloudflare Pages choose no framework and no build command; publish from the repository root. This repository does not deploy automatically until hosting is configured.

## Important limitation

This is a public research landing page, **not a live bill database**. The separate ChatGPT daily automation is not connected to this GitHub repository, and it does not automatically publish reports here. Future publishing can use manually reviewed Markdown/JSON files or an optional feed integration.

## Editorial standards

Use primary official records, cite each substantive claim, distinguish bills from enacted laws and allegations from proven facts, preserve bill-version dates, and identify unknown or unavailable data. Financial relationships alone do not prove misconduct.
